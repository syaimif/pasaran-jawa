Diperlukan agar event bisa ditambahkan langsung ke Google Kalender tanpa buka tab satu per satu. Gratis, ikuti langkah berikut:
1. Buka Google Cloud Console → Credentials
2. Klik + Create Credentials → OAuth Client ID → pilih Web application
3. Di Authorised JavaScript origins tambahkan URL aplikasi Anda (mis: https://nama-app.vercel.app atau http://localhost:8080)
4. Aktifkan Google Calendar API di API Library
